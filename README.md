# Neptune 自动充电脚本

每半小时检测昨晚断电的充电桩，目标端口空闲时自动恢复充电。

## 功能

- 检测昨天 23:45 - 今天 00:35 之间因断电结束的充电记录
- 自动在同一设备/端口恢复充电
- 按余额最大化充电，最长 480 分钟
- 全天每半小时检查一次；目标端口正在充电或处于其他非空闲状态时直接退出，不发起充电请求，也不重试
- **智能重试**：失败后 10 分钟重试，最多 3 次

## 部署方式

### 方式一：GitHub Actions（推荐，无需服务器）

1. **Fork 本仓库**

2. **配置 Secrets**

   进入你的仓库 → Settings → Secrets and variables → Actions → New repository secret

   添加以下 Secrets：

   | Name | Value |
   |------|-------|
   | `NEPTUNE_OPEN_ID` | 你的 openId |
   | `NEPTUNE_AREA_ID` | 6 |
   | `NEPTUNE_EMPLOYEE_ID` | 你的 employeeId |

3. **启用 Actions**

   进入 Actions 标签页，点击 "I understand my workflows, go ahead and enable them"

4. **测试运行**

   Actions → Neptune Auto Charge → Run workflow → Run workflow

   脚本全天每半小时运行一次，即北京时间每小时的 **00 分、30 分**，每天计划触发 48 次。

   GitHub Actions 使用 UTC，定时配置为：

   ```yaml
   schedule:
     - cron: '0,30 * * * *'
   ```

   GitHub 的 scheduled workflow 可能因调度负载延迟。网络或接口错误仍会触发最多 3 次、间隔 10 分钟的 Python 重试；目标端口非空闲时直接结束本次运行。

### 方式二：VPS 定时任务

```bash
# 克隆仓库
git clone https://github.com/你的用户名/neptune-auto-charger.git
cd neptune-auto-charger

# 安装依赖
pip install -r requirements.txt

# 配置
cp .env.example .env
nano .env  # 编辑填写你的信息

# 设置定时任务
crontab -e
# 添加：
0,30 * * * * cd /path/to/neptune-auto-charger && python3 main.py >> charge.log 2>&1
```

## 配置说明

| 变量 | 说明 | 获取方式 |
|------|------|---------|
| `NEPTUNE_OPEN_ID` | 微信用户标识 | 抓包获取 |
| `NEPTUNE_AREA_ID` | 区域 ID | 固定为 6 |
| `NEPTUNE_EMPLOYEE_ID` | 用户 ID | 抓包获取 |

### 如何获取这些信息？

1. 使用抓包工具（Fiddler/Charles）抓取微信小程序请求
2. 找到 `www.szlzxn.cn` 的请求
3. 从请求参数中获取 `openId` 和 `employeeId`

## 重试策略

每次运行遇到网络或接口错误等错误时执行以下重试：

- 启动时立即第一次尝试
- 失败后 10 分钟第二次尝试
- 再失败后 10 分钟第三次尝试

目标端口非空闲或没有符合条件的断电记录时，脚本直接退出，不等待重试。下一次定时检查仍按每小时 **00 分、30 分**运行。

程序检测的断电记录窗口为 **昨日 23:45 至今日 00:35**。充电桩稍晚开启时，后续的半小时定时检查仍可尝试恢复充电。脚本在发送启动请求前还会再次检查目标端口，非空闲时立即跳过。

## 注意事项

- 脚本只会恢复**昨晚断电**的充电，不会触发前天的记录
- 保持余额充足（至少 1 元）
- `openId` 相当于你的账户密码，请妥善保管
